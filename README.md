# Stillfeed browser extension

A free browser extension that hides Reels, Shorts and endless feeds on Instagram, YouTube, X, Reddit, Facebook, TikTok, LinkedIn and Snapchat, and leaves messages, profiles, search and the posts you open alone. No account, and nothing leaves your browser.

- Chrome, Brave, Edge, Opera, Arc: [Chrome Web Store](https://chromewebstore.google.com/detail/stillfeed-hide-reels-shor/hbdcekalnlndonbliecjfiidffcppmao)
- Firefox 128 or newer: [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/stillfeed/)
- Install steps and a manual ZIP: [stillfeed.pro/extension](https://stillfeed.pro/extension/)
- The iPhone app and the guides: [stillfeed.pro](https://stillfeed.pro/)

## What it does

- Hides the Reels, Shorts, For You, Explore and r/popular style surfaces, with a switch per site.
- A daily limit, a session timer, quiet hours, a pause before opening and grayscale.
- It does not block arbitrary websites.

Per-site detail: [stillfeed.pro/extension](https://stillfeed.pro/extension/). Privacy: [stillfeed.pro/privacy](https://stillfeed.pro/privacy/#browser-extension).
